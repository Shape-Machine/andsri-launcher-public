# Home screen

One scrolling screen keeps essential information and every app immediately accessible.

## Experience

- Places date and time at the top, with Settings beside the clock.
- Opens the system clock from the time and system calendar from the date.
- Shows optional weather, favorites, then the alphabetical app list.
- Displays favorites as a responsive four- or five-column icon grid with no maximum count.
- Keeps favorite apps in the alphabetical list.
- Collapses the app list by default when favorites exist and remembers the choice.
- Expands the app list permanently when no favorites exist.
- Returns to the top when Home is pressed again.

## Boundaries

- One screen; no pages, drawer, search, recents, suggestions, groups, badges, headings, fast scroller, custom gestures, or animations.
- Portrait only. Android status, navigation, notifications, and Quick Settings remain standard.
