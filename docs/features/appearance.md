# Appearance

Curated controls personalize the launcher without adding runtime visual overhead.

## Background

- Follow Android’s light/dark mode or select either mode manually.
- Use the system wallpaper or choose an image from the gallery.
- Fade wallpaper toward white in Light mode and black in Dark mode.
- Replace wallpaper with pure white or pure black through Solid background.

## Layout and type

- Select Compact, Standard, or Emphasized clock layouts.
- Select Compact, Standard, or Comfortable list density.
- Choose Atkinson Hyperlegible Next, Newsreader, or Maple Mono.
- Apply typography and density to Home and Settings.

## Apps and icons

- Show text only or icons with text.
- Choose application icons or bundled Lawnicons, Arcticons, Appstract, Cuscon, Delta, Dollphone, and Snow themes.
- Generate a matching letter tile when a theme lacks an app icon.

## Boundaries

- No live blur, parallax, visual animation, arbitrary fonts, or third-party icon-pack integration.
